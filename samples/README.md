# Samples

Example input/output files used for manual testing.

| File | Purpose |
|------|---------|
| `Pronti_Deed_Exit_Risk_Table.md` | Sample Markdown source |
| `Pronti_Deed_Exit_Risk_Table.pdf` | Example PDF output |

Convert via CLI:

```bash
python scripts/md_converter.py samples/Pronti_Deed_Exit_Risk_Table.md -f pdf -o samples/out
```

Or use the web UI at `/`.
